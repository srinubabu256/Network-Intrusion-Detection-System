🔵 SLIDE 2: Introduction

The rapid growth of internet technologies has increased cybersecurity threats.

Organizations rely heavily on secure network infrastructures.

Traditional security systems are insufficient against modern cyber attacks.

Machine Learning provides intelligent automated detection.

This project implements an ML-based Network Intrusion Detection System (NIDS).

🔵 SLIDE 3: Problem Statement

Traditional Intrusion Detection Systems (IDS) are rule-based.

Cannot detect unknown (zero-day) attacks.

Produce high false positive rates.

Require frequent manual updates.

Need an automated data-driven solution.

🔵 SLIDE 4: Objectives of the Project

Develop a Machine Learning-based intrusion detection system.

Train the model using KDD Cup 99 dataset.

Achieve high accuracy (>90%).

Deploy the system using Flask.

Provide a user-friendly web interface.

🔵 SLIDE 5: Scope of the Project

Detect malicious network traffic.

Classify traffic as Normal or Attack.

Provide real-time prediction.

Display results via web application.

Suitable for small and medium organizations.

🔵 SLIDE 6: Types of Cyber Attacks

Denial of Service (DoS)

Probe Attacks

Remote to Local (R2L)

User to Root (U2R)

Malware Injection

Unauthorized Access

🔵 SLIDE 7: Dataset Used

Dataset: KDD Cup 99

Publicly available cybersecurity dataset.

Contains labeled network traffic records.

Includes 41 features.

Used for supervised learning.

Features include:

duration

src_bytes

dst_bytes

wrong_fragment

urgent

label

🔵 SLIDE 8: Data Preprocessing

Removed unnecessary fields.

Handled missing values.

Converted categorical values into numerical format.

Applied Label Encoding.

Split dataset into:

80% Training Data

20% Testing Data

🔵 SLIDE 9: Machine Learning Algorithm

Algorithm Used: Random Forest

Why Random Forest?

Ensemble learning method.

Combines multiple decision trees.

Reduces overfitting.

High classification accuracy.

Suitable for large datasets.

🔵 SLIDE 10: Model Training Process

Load dataset using Pandas.

Preprocess data.

Split into train and test sets.

Train Random Forest model.

Evaluate model performance.

Save model as .pkl file.
