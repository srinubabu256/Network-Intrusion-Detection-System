# Network Intrusion Detection System (NIDS) - AI Enhanced

This project is a comprehensive Network Intrusion Detection System featuring a Python Flask backend with real-time traffic simulation and a modern React frontend dashboard. It utilizes machine learning (Random Forest) to classify network traffic and integrates Generative AI (OpenAI/Gemini) for advanced threat analysis.

## 🚀 Features

- **Real-time Traffic Simulation**: Generates network traffic patterns based on the NSL-KDD dataset.
- **AI-Powered Detection**: Hybird detection using Random Forest for classification and LLMs for threat analysis.
- **Interactive Dashboard**: 
    - Live packet stream visualization.
    - Real-time charts for protocol distribution and attack types.
    - System health monitoring (CPU, Network Load).
- **Threat Intelligence**: Automated analysis of critical threats using OpenAI GPT-4 or Google Gemini Pro.
- **Modern UI/UX**: Dark-themed, responsive interface built with React, Tailwind CSS, and Recharts.

## 🛠️ Tech Stack

- **Backend**: Python, Flask, Flask-SocketIO, Scikit-learn, Pandas, OpenAI/Google-GenerativeAI APIs.
- **Frontend**: React (Vite), Tailwind CSS, Recharts, Lucide React, Socket.io-client.
- **Dataset**: NSL-KDD (Network Security Laboratory - Knowledge Discovery in Databases).

## 📦 Installation & Usage

### Method 1: One-Click Start (Recommended)

Simply double-click the `start.bat` file in the root directory. This script will:
1. Check for Python and Node.js.
2. Install all backend and frontend dependencies automatically.
3. Launch the Flask server (backend) and Vite server (frontend).
4. Open the dashboard in your default browser.

### Method 2: Manual Setup

**Backend:**
```bash
# Install dependencies
pip install -r requirements.txt

# Run the server
python app.py
```

**Frontend:**
```bash
cd client
npm install
npm run dev
```

## 🔑 Configuration

The application uses an `.env` file for API keys. This has been pre-configured with your provided keys:
- `OPENAI_API_KEY`
- `GEMINI_API_KEY`

You can modify settings (like the active AI provider) directly from the **Settings** page in the dashboard.

## 📊 Dashboard Overview

1.  **Dashboard**: The main view showing live stats, charts, and the traffic table.
2.  **Simulation Controls**: Use the sidebar to Start/Stop the traffic simulation.
3.  **Active Threats**: Critical alerts appear here with AI-generated analysis.

## ⚠️ Troubleshooting

- **Dataset Not Found**: Ensure the `NSL_Dataset` folder or `dataset` folder exists in the root.
- **Dependencies**: If `start.bat` fails, try running `pip install -r requirements.txt` manually to see specific errors.
- **Port Conflicts**: The app uses ports `5000` (Backend) and `5173` (Frontend). Ensure these are free.
